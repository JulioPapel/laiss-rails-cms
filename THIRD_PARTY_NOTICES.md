# Third-party notices

laiss-rails-cms is built on open software. This file keeps the attribution and
the canonical URL for each dependency that the admin visibly credits, so the
credit is verifiable without the admin sending an author to an external site.

The dashboard footer lists these four names as text. It previously linked them
with `target="_blank"`, which opened a new browser tab from inside the CMS.
Attribution does not require a hyperlink, so the link was removed and the URLs
live here instead.

| Component | Licence | Canonical URL |
| --- | --- | --- |
| Ruby on Rails | MIT | https://rubyonrails.org |
| Shoelace | MIT | https://shoelace.style |
| TinyMCE | MIT (community edition) | https://www.tiny.cloud |
| Remix Icon | Apache 2.0 | https://remixicon.com |

For the engine itself, see [`LICENSE`](LICENSE), which retains the upstream
AlchemyCMS BSD-3-Clause notice as required.
